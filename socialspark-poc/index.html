🧩 Install SocialSpark Extension

  1. Download the extension files from the link below
  2. Open Chrome and go to chrome://extensions/
  3. Turn on "Developer mode" (toggle top right)
  4. Click "Load unpacked"
  5. Select the socialspark-extension folder
  6. Done! The extension icon will appear in your toolbar
💡 Pro tip: Click the puzzle piece icon in Chrome toolbar, find "SocialSpark", and click the pin to keep it visible.
