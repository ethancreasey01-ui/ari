## 🌅 MORNING ROUTINE (5-10 minutes)

### Step 1: Cleanse (1 min)
- **Product**: CeraVe Hydrating Cleanser OR Vanicream Gentle Cleanser
- **Price**: ~$15-20
- **Where**: Chemist Warehouse, Priceline, Amazon AU
- **How**: Splash face with water, gentle cleanser, rinse

### Step 2: Vitamin C Serum (30 sec)
- **Product**: The Ordinary Vitamin C Suspension 23% OR Timeless Vitamin C
- **Price**: ~$15-30
- **Where**: Adore Beauty, The Ordinary website, Amazon AU
- **How**: 3-4 drops, pat onto face, let absorb 1-2 min

### Step 3: Moisturizer (30 sec)
- **Product**: CeraVe Daily Moisturizing Lotion
- **Price**: ~$20-25
- **Where**: Any pharmacy
- **How**: Apply to face and neck

### Step 4: Sunscreen (30 sec) ⭐ CRITICAL
- **Product**: Blue Lizard Sensitive SPF 30+ OR Cancer Council Face Day Wear
- **Price**: ~$15-25
- **Where**: Any pharmacy
- **How**: Apply generously, last step before makeup

**UV Rule**: Check UV index on iPhone weather app. If 3+, use SPF.

## 🌙 EVENING ROUTINE (5-10 minutes)

## ☀️ UV PROTECTION STRATEGY

### Daily:
- Check UV index on iPhone weather app
- UV 0-2: Minimal protection needed
- UV 3-5: SPF 30+, hat if outside long
- UV 6+: SPF 30+, hat, seek shade, UV umbrella if beach/pool

### Timing:
- ✅ Get sun exposure: Before 10am or after 4pm (vitamin D)
- ❌ Limit exposure: 10am-4pm (high UV)

### Products:
- **Everyday**: Cancer Council Face Day Wear SPF 50+ ($8-12 at supermarket)
- **Beach/Outdoor**: Blue Lizard Sensitive SPF 30+ ($20-25)
- **Hat**: Wide-brim hat for extended outdoor time

## ⚠️ IMPORTANT TIPS

### Retinol Rules:
- Start 2x/week, increase slowly
- Apply AFTER moisturizer (sandwich method)
- Expect slight redness/peeling at first (normal)
- If too irritated → cut back frequency
- Always use SPF (retinol makes skin sun-sensitive)
- Don't use if pregnant/planning pregnancy

### Red Light Therapy:
- Consistency matters (daily is best)
- 10-20 minutes is enough
- No side effects, safe for long-term
- Can do face + body in same session

### Supplements:
- Collagen: 10g daily minimum
- Take with food for better absorption
- Give it 3 months before judging results
- Quality matters (don't buy cheapest)

### Diet:
- Sugar is #1 skin ager (cut it!)
- Hydration is crucial
- EVOO is liquid gold for skin
- Blueberries are skin superfood

## 🆘 QUESTIONS?

**If you get confused:**
- Start with sunscreen + vitamin C only
- Add one new product every 2 weeks
- Don't overwhelm yourself
- Simple routine done daily > complex routine done sometimes

**If skin gets irritated:**
- Cut back retinol frequency
- Simplify routine (cleanse + moisturize only)
- Add products back one by one
- See dermatologist if persistent

**If budget is tight:**
- Skip retinol initially
- Get cheaper cleanser/moisturizer
- Focus on sunscreen + collagen + diet
- Add other products over time
