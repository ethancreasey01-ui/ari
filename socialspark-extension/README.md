# SocialSpark AI - Browser Extension

## What is this?

One-click posting from SocialSpark to Facebook and Facebook Groups. No more copy/paste!

## Features

✅ One-click post to Facebook Feed  
✅ One-click post to Facebook Groups  
✅ Auto-fills content in Facebook composer  
✅ Edit before posting (you stay in control)  
✅ Works with Chrome and Firefox  
✅ Free with SocialSpark subscription

## Installation

### Chrome (2 minutes)

1. Download the `socialspark-extension` folder
2. Open Chrome → go to `chrome://extensions/`
3. Turn on **Developer mode** (toggle top right)
4. Click **"Load unpacked"**
5. Select the `socialspark-extension` folder
6. Done! Extension appears in your toolbar

**Pin the extension:** Click puzzle piece → find "SocialSpark" → click pin

## How to Use

1. **Open SocialSpark Dashboard** - Generate content for your business
2. **Click "Post to Facebook"** - Blue button on any post
3. **Facebook opens** - Content auto-fills in composer
4. **Click "Post"** - You control what goes live

That's it! 5 seconds instead of 5 minutes.
