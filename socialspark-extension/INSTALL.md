# SocialSpark Browser Extension - Installation Guide

## Quick Install (2 minutes)

### Step 1: Download Extension Files
1. Download the `socialspark-extension` folder
2. Save it to your computer

### Step 2: Open Chrome Extensions
1. Open Chrome browser
2. Go to `chrome://extensions/`
3. Turn on "Developer mode" (toggle in top right)

### Step 3: Load Extension
1. Click "Load unpacked"
2. Select the `socialspark-extension` folder
3. Extension will appear in your toolbar!

### Step 4: Pin Extension
1. Click the puzzle piece icon (extensions)
2. Find "SocialSpark"
3. Click the pin icon to keep it visible

---

## How to Use

### 1. Open SocialSpark Dashboard
- Go to your dashboard: `http://localhost:8083` (or your hosted URL)
- Generate content for your business

### 2. Click "Post to Facebook"
- Each post has a blue "Post to Facebook" button
- Click it → Facebook opens in new tab
- Content is automatically filled in

### 3. Publish on Facebook
- Review the filled content
- Add any images if needed
- Click "Post" on Facebook
- Done! 🎉

## Troubleshooting

### Extension not working?
- Make sure you're logged into Facebook
- Refresh Facebook page if composer doesn't appear
- Check that extension is enabled (green toggle)

### Content not filling?
- Wait 2-3 seconds after Facebook opens
- Make sure you're on facebook.com
- Try refreshing the Facebook page

### Want to post to Groups?
- Use "Post to Groups" button
- Navigate to your Facebook Group first
- Or let it open Facebook and you go to the group
